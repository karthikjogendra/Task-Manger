**Project Title: Cloud-Based Task Management System with Automated CI/CD Pipeline**

**Objective:** To develop a scalable web-based task management application with automated software build, testing, and deployment.

**Key Features:**
- Developed REST APIs for CRUD operations.
- Implemented user authentication and task management.
- Designed a responsive frontend using React.js.
- Integrated Spring Boot with a relational database.
- Configured Jenkins for automated CI/CD workflows.
- Used Docker to containerize the application.
- Deployed the application on AWS EC2.
- Implemented application logging and basic monitoring.

**Technologies:** Java, Spring Boot, React.js, REST APIs, MySQL, Git, GitHub, Jenkins, Docker, AWS EC2.
